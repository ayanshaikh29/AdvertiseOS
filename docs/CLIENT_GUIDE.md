# Client Guide — AdvertiseOS (for the approver)

## Your monthly loop (10 minutes)
1. Open **Briefs → New brief**. Enter month, goal (e.g. "50 leads for web design"), budget, offers.
2. Press **Run AI team**. Wait ~1 minute. The CEO agent plans, specialists write + design, CEO reviews.
3. Open the **Approval inbox**. Each card shows the creative, caption, hashtags, CEO score.
   - **Approve** good items. **Reject** bad ones — always write a reason (the AI learns from it: you'll see "AI learned: …").
4. Approved items → **Schedule**, then post manually and **Mark as posted** (auto-posting stays off until you approve Meta access).
5. End of month: **Analytics → Upload CSV** (Meta/Google export) → **Generate weekly report**. Real numbers only — never estimates.

## Rules the AI follows
- Nothing publishes or spends money without your tap.
- It never invents awards, clients, reviews, or statistics. If a fact is missing, it says so.
- Anything labeled "Sample data" is demo content, not real performance.

## Pages
- **Dashboard**: approvals pending, spend, what agents are doing.
- **Calendar**: the 30-day plan. **Assets**: every creative, downloadable.
- **Team**: agent scorecards + AI self-improvement proposals (you accept/reject).
- **Settings**: spend limit, audit log (who approved what, when).
